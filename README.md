# Machine_Learning_Crypto_Transactions
Anomaly Detection in Cryptocurrency Transactions Using Machine Learning
This project aimed to analyze blockchain transaction data using machine learning. I applied K-Means clustering and PCA for pattern detection and dimensionality reduction. A Random Forest model was trained to classify transactions, improving detection accuracy. Feature scaling and hyperparameter tuning optimized model performance. I built a data-driven approach to identifying fraudulent or high-risk transactions, enhancing security and decision-making in crypto analytics.
